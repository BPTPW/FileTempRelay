# 文件临时仓库

一个轻量的本地临时文件仓库服务，提供网页端上传与管理，支持设置访问口令，可选 WebAuthn 验证。适合在内网或个人设备上快速共享/临时存放文件和文本。

## 功能概览

- 网页端上传文件、粘贴文本并生成临时记录
- 口令保护访问，可选 WebAuthn（更安全的无密码登录）
- 记录索引与日志保存，便于追踪
- 定时清理过期内容（基于服务端策略）

## 适用场景

- 内网或个人电脑之间临时共享文件
- 快速把文件/文本放到浏览器里备查
- 小型团队的短期文件流转

## 使用方式

### 1. 安装依赖

```bash
pnpm install
```

### 2. 配置

复制配置文件并按需修改：

```bash
cp config-example.json config.json
```

配置示例说明：

- `password`：访问口令
- `sizeLimit`：上传大小限制（字节）
- `addWebAuthn`：是否启用 WebAuthn

### 3. 启动

```bash
pnpm start
```

启动后用浏览器访问服务地址即可使用。

## 目录结构（简要）

- `data/`：索引与存储数据
- `logs/`：访问/操作日志
- `assets/`：静态资源

## 说明

- 默认使用本地文件系统存储。
- WebAuthn 需要浏览器和设备支持。
