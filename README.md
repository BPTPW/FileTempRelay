# 文件临时仓库

一个轻量的本地临时文件仓库服务，提供网页端上传与管理，支持设置访问口令，可选 WebAuthn 验证。适合在内网或个人设备上快速共享/临时存放文件和文本。

## 功能概览

- 网页端上传文件、粘贴文本并生成临时记录
- 口令保护访问，可选 WebAuthn（更安全的无密码登录）
- 记录索引与日志保存，便于追踪
- 定时清理过期内容（基于服务端策略）

## 适用场景

- 内网或个人电脑之间临时共享文件
- 快速把文件/文本放到浏览器里备查
- 小型团队的短期文件流转

## 使用方式

### 1. 安装依赖

```bash
pnpm install
```

### 2. 配置

复制配置文件并按需修改：

```bash
cp config-example.json config.json
```

配置示例说明：

- `password`：访问口令
- `sizeLimit`：上传大小限制（字节）
- `addWebAuthn`：是否允许添加 WebAuthn 通信密钥

### 3. 启动

```bash
npm start
```

启动后用浏览器访问服务地址即可使用。

## 目录结构（简要）

- `data/`：索引与存储数据
- `logs/`：访问/操作日志
- `assets/`：静态资源

## 说明

- 默认使用本地文件系统存储。
- WebAuthn 需要浏览器和设备支持。

## API 接口

### 基础与内容管理接口

#### 1. 验证密码鉴权

- **路径**：`/api/auth`
- **请求方式**：`POST`
- **请求参数** (JSON)：

    | 参数名     | 数据类型 | 含义     |
    | :--------- | :------- | :------- |
    | `password` | String   | 访问口令 |

- **返回内容** (JSON)：

    | 键名        | 数据类型 | 含义                             |
    | :---------- | :------- | :------------------------------- |
    | `token`     | String   | 鉴权令牌（登录成功时返回）       |
    | `expiresAt` | Number   | 令牌过期时间戳（登录成功时返回） |
    | `error`     | String   | 错误信息（登录失败时返回）       |

#### 2. 获取列表数据

- **路径**：`/api/list`
- **请求方式**：`GET`
- **请求参数**：无
- **返回内容** (JSON)：

    | 键名          | 数据类型 | 含义                                 |
    | :------------ | :------- | :----------------------------------- |
    | `items`       | Array    | 项目列表（包含文件和文本的信息）     |
    | `sizeLimit`   | Number   | 服务端配置的上传文件大小限制（字节） |
    | `addWebAuthn` | Boolean  | 服务端是否配置允许添加通行密钥       |

#### 3. 上传文件

- **路径**：`/api/upload`
- **请求方式**：`POST`
- **请求头**：需要鉴权令牌，`x-upload-token: <token>` 或 `Authorization: Bearer <token>`
- **请求参数** (`multipart/form-data`)：

    | 参数名 | 数据类型 | 含义             |
    | :----- | :------- | :--------------- |
    | `file` | File     | 要上传的文件内容 |

- **返回内容** (JSON)：

    | 键名    | 数据类型 | 含义                                       |
    | :------ | :------- | :----------------------------------------- |
    | `ok`    | Boolean  | 上传是否成功（成功时返回 `true`）          |
    | `item`  | Object   | 上传成功后生成的文件项目信息（成功时返回） |
    | `error` | String   | 错误信息（失败时返回）                     |

#### 4. 上传文本

- **路径**：`/api/text`
- **请求方式**：`POST`
- **请求头**：需要鉴权令牌，同上传接口
- **请求参数** (JSON)：

    | 参数名 | 数据类型 | 含义               |
    | :----- | :------- | :----------------- |
    | `text` | String   | 要保存的纯文本内容 |

- **返回内容** (JSON)：

    | 键名    | 数据类型 | 含义                                   |
    | :------ | :------- | :------------------------------------- |
    | `ok`    | Boolean  | 操作是否成功（成功时返回 `true`）      |
    | `item`  | Object   | 成功后生成的文本项目信息（成功时返回） |
    | `error` | String   | 错误信息（失败时返回）                 |

#### 5. 下载文件

- **路径**：`/api/download/:id`
- **请求方式**：`GET`
- **请求参数** (路径参数)：

    | 参数名 | 数据类型 | 含义              |
    | :----- | :------- | :---------------- |
    | `id`   | String   | 目标文件的项目 ID |

- **返回内容**：直接返回文件的二进制流 (`application/octet-stream`)

#### 6. 读取纯文本

- **路径**：`/api/text/:id`
- **请求方式**：`GET`
- **请求参数** (路径参数)：

    | 参数名 | 数据类型 | 含义              |
    | :----- | :------- | :---------------- |
    | `id`   | String   | 目标文本的项目 ID |

- **返回内容**：直接返回纯文本字符串 (`text/plain`)

#### 7. 删除项目

- **路径**：`/api/item/:id`
- **请求方式**：`DELETE`
- **请求参数** (路径参数)：

    | 参数名 | 数据类型 | 含义            |
    | :----- | :------- | :-------------- |
    | `id`   | String   | 要删除的项目 ID |

- **返回内容** (JSON)：

    | 键名    | 数据类型 | 含义                              |
    | :------ | :------- | :-------------------------------- |
    | `ok`    | Boolean  | 删除是否成功（成功时返回 `true`） |
    | `error` | String   | 错误信息（失败时返回）            |

### WebAuthn (通行密钥)接口

#### 1. 注册获取参数 (Options)

- **路径**：`/api/webauthn/register/options`
- **请求方式**：`POST`
- **请求参数** (JSON)：

    | 参数名     | 数据类型 | 含义                           |
    | :--------- | :------- | :----------------------------- |
    | `username` | String   | 要向服务端注册通行密钥的用户名 |

- **返回内容** (JSON)：

    | 键名        | 数据类型 | 含义                      |
    | :---------- | :------- | :------------------------ |
    | `options`   | Object   | WebAuthn 注册选项配置对象 |
    | `requestId` | String   | 当前注册请求的唯一标识符  |
    | `error`     | String   | 错误信息（失败时返回）    |

#### 2. 注册验证 (Verify)

- **路径**：`/api/webauthn/register/verify`
- **请求方式**：`POST`
- **请求参数** (JSON)：

    | 参数名      | 数据类型 | 含义                               |
    | :---------- | :------- | :--------------------------------- |
    | `requestId` | String   | 上一步获取的请求唯一标识符         |
    | `response`  | Object   | 浏览器 WebAuthn API 产生的响应数据 |

- **返回内容** (JSON)：

    | 键名    | 数据类型 | 含义                                  |
    | :------ | :------- | :------------------------------------ |
    | `ok`    | Boolean  | 注册验证是否成功（成功时返回 `true`） |
    | `error` | String   | 错误信息（验证失败时返回）            |

#### 3. 登录获取参数 (Options)

- **路径**：`/api/webauthn/auth/options`
- **请求方式**：`POST`
- **请求参数** (JSON)：

    | 参数名     | 数据类型 | 含义                                             |
    | :--------- | :------- | :----------------------------------------------- |
    | `username` | String   | (可选)要登录的用户名，不传则将尝试多账号列表发现 |

- **返回内容** (JSON)：

    | 键名        | 数据类型 | 含义                            |
    | :---------- | :------- | :------------------------------ |
    | `options`   | Object   | WebAuthn 登录(认证)选项配置对象 |
    | `requestId` | String   | 当前登录请求的唯一标识符        |
    | `error`     | String   | 错误信息（如未找到密钥时返回）  |

#### 4. 登录验证 (Verify)

- **路径**：`/api/webauthn/auth/verify`
- **请求方式**：`POST`
- **请求参数** (JSON)：

    | 参数名      | 数据类型 | 含义                                   |
    | :---------- | :------- | :------------------------------------- |
    | `requestId` | String   | 上一步获取的请求唯一标识符             |
    | `response`  | Object   | 浏览器 WebAuthn API 产生的认证响应数据 |

- **返回内容** (JSON)：

    | 键名        | 数据类型 | 含义                       |
    | :---------- | :------- | :------------------------- |
    | `token`     | String   | 登录成功发放的鉴权令牌     |
    | `expiresAt` | Number   | 令牌的过期时间戳           |
    | `error`     | String   | 错误信息（验证失败时返回） |

#### 5. 获取凭证列表

- **路径**：`/api/webauthn/credentials`
- **请求方式**：`GET`
- **请求头**：需要鉴权令牌
- **请求参数**：无
- **返回内容** (JSON)：

    | 键名          | 数据类型 | 含义                                                   |
    | :------------ | :------- | :----------------------------------------------------- |
    | `credentials` | Array    | 包含系统内已注册的所有通行密钥列表及其用户名、注册时间 |
    | `error`       | String   | 错误信息（鉴权失败时返回）                             |

#### 6. 删除凭证

- **路径**：`/api/webauthn/credential/:id`
- **请求方式**：`DELETE`
- **请求头**：需要鉴权令牌
- **请求参数** (路径参数)：

    | 参数名 | 数据类型 | 含义            |
    | :----- | :------- | :-------------- |
    | `id`   | String   | 要删除的凭证 ID |

- **返回内容** (JSON)：

    | 键名    | 数据类型 | 含义                                     |
    | :------ | :------- | :--------------------------------------- |
    | `ok`    | Boolean  | 操作是否成功（成功时返回 `true`）        |
    | `error` | String   | 错误信息（如鉴权失败或未找到记录时返回） |
